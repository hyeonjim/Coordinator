# README — 학습 및 기여 정리

## 1. 개요
프로젝트 주제 선정 및 기획 단계에서 **실시간 협업/가이드 UX**, **AI 활용**, **데이터 연동** 중심으로 아이디어를 제시하고,
최종 채택된 **실시간 코드 공유 + TDD 테스트** 주제에 대해 **UI 시안(피그마) 제작**을 통해 팀 논의를 구체화했습니다.  
또한 개발 전 단계에서 **Figma 역량 강화**, **React 학습을 위한 JavaScript 재학습**을 진행했습니다.

---

## 2. 내가 공부/리서치한 핵심 내용

### 2.1 실시간 기능(Real-time) 설계 관점 학습
- “옆에서 알려주는 느낌”을 만들기 위해 필요한 요소를 기능 단위로 분해
  - 마우스 좌표(x, y), 스크롤 위치, 드로잉 데이터 등 **이벤트 기반 동기화** 개념 정리
  - 지연이 커질수록 UX가 급격히 나빠지는 **실시간 상호작용 특성** 이해
- 기술 스택 개념 정리
  - **WebSocket**: 커서/스크롤/드로잉 등 실시간 데이터 전송
  - **WebRTC(Audio)**: 웹 내 음성 통화
  - **Canvas**: 하이라이트 펜/동그라미 등 실시간 표시
  - **DOM Observer(선택)**: 화면 변화 감지 아이디어 검토

### 2.2 서비스 기획 관점에서의 문제 정의/해결 구조 학습
- 타겟 사용자의 “막히는 지점”을 구체적인 상황으로 정의하고 솔루션을 MVP로 축소하는 방식 학습
- **설치가 필요한 원격제어**와 달리, **설치 없는 웹 기반 가이드**가 가지는 장단점 비교

### 2.3 외부 데이터 활용 관점 학습(부동산 아이디어에서)
- 실거래가/면적/비교 데이터를 근거로 보고서를 자동 생성하는 흐름 구상
- 공공데이터 활용 가능성 확인  
  - 국토교통부 아파트 매매 실거래가(Open API) 참고: https://www.data.go.kr/data/15126469/openapi.do

### 2.4 디자인 툴(Figma) 학습
- 템플릿/플러그인을 탐색하며 **와이어프레임/목업 제작**에 집중
- “말로만 설명하지 않고” 팀이 같은 화면을 보며 논의할 수 있도록 **작업환경 시안**을 만드는 방식 학습

### 2.5 JavaScript 재학습(React 학습 전 준비)
- React 학습 전, JS 기본기 재정비를 진행
  - DOM/이벤트 흐름, 비동기 처리(Promise/async-await) 등 핵심 개념 복습
  - 이후 React로 넘어가기 위한 기반 체력 확보

## 3. 아이디어 회의에서 제시한 내용(기획/학습 중심)

### 3.1 Ghost Cursor — “대신 커서해 드립니다”
**상황/문제**
- 디지털 취약계층(부모님 등)에게 전화로 “오른쪽 버튼 눌러봐” 안내 시 서로 답답함
- 캡처 주고받기 방식은 느리고 반복 비용이 큼

**해결 아이디어(MVP)**
- 링크로 방 입장 → 권한 동의 → 실시간 가이드 시작
- 핵심 기능
  - Co-browsing: 호스트 마우스 이동이 게스트 화면에 **유령 커서(투명도 높게)**로 표시
  - 하이라이트 펜: 화면 위에 동그라미/표시(캔버스 오버레이)
  - 웹 내 음성 대화(WebRTC)

**학습 포인트**
- 커서/스크롤/드로잉 등 “가이드 이벤트”를 실시간으로 동기화하는 구조 이해

---

### 3.2 온라인 임장/매물 점검 보조 아이디어(부동산)
**문제**
- 중개인 일정/동선에 따라 집을 ‘랜덤’하게 보게 되는 비효율
- 원하는 집만 효율적으로 추리고, 확인해야 할 체크포인트를 놓치지 않게 하고 싶음

**해결 흐름**
- 상담 예약(부동산별 일정 선택)
- 한 집 단위 PDF 리포트 자동 생성(실거래가/면적/비교 정보 + 체크리스트/하자 기록)
- 영상 기반 하자 리스트업, 체크리스트 기반 확인 유도, AI 추천 체크리스트(“다른 사람들은 이런 걸 물어봤어요”)
- GPS Fencing(중개인이 매물 인근에 있어야 인증) 같은 제약 조건도 검토

**학습 포인트**
- “현장 정보 + 데이터 + AI”를 결합해 사용자의 의사결정 비용을 줄이는 구조 설계

## 4. 최종 채택 주제에서의 기여(시안/논의 촉진)
- 주제 선정 기획 단계에서 **아이디어를 최대한 많이 제시**하고, 단순 제안이 아니라 **시안(화면 예시)을 함께 준비**하여 논의에 참여
- 최종 채택된 **실시간 코드 공유 + TDD 테스트** 주제에 대해
  - 피그마로 작업환경/UI 시안 제작
  - 팀원들이 기능을 구체적으로 상상할 수 있도록 화면 기반으로 기능 논의 유도

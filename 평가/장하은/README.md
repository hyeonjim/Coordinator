# 프로젝트 README

## 개요

본 프로젝트는 다양한 사회 문제를 AI 기술을 활용하여 해결하는 혁신적인 서비스들을 개발하는 프로젝트입니다. 실시간 코드 공유, 원격 화상 상담, AI 기반 중재 및 모니터링 기능을 핵심 기술 스택으로 하여 여러 아이디어를 동시에 추진 중입니다.

---

## 공부/리서치 핵심 내용

### 1. 아이디어 조사 회의 진행
- 다양한 비즈니스 모델과 타겟층 분석
- 시장 규모 및 사용자 니즈 파악
- 경쟁사 분석 및 차별점 도출

### 2. 기능 요구사항 작성
- 각 아이디어별 핵심 기능 정의
- 사용자 플로우 및 사용 시나리오 분석
- 우선순위 설정

### 3. 실시간 코드 공유 서비스 기술 조사
- 코드 실행 방안 
- 깃 푸쉬 방법
- 테스트 코드 생성

### 4. Jira 사용법 학습
- 프로젝트 관리 및 이슈 추적 시스템 이해
- 팀 협업 체계 수립

## 아이디어 회의에서 제시한 내용

### 신규 아이디어 제안

| 아이디어 | 설명 | 타겟층 |
|---------|------|--------|
| **폐기 위기 농산물 타임어택** | 판매 기한 임박 농산물의 빠른 거래 플랫폼 | 소비자, 농민 |
| **면접 & 재판 준비** | AI를 통한 예상 질문 및 답변 연습 | 취준생, 소송 당사자 |
| **AI 경호원** | 밤길 보행자 안전 보호 서비스 | 야간 외출자 |
| **세이프 워크** | 직장 내 안전 및 괴롭힘 방지 시스템 | 직장인 |
| **디지털 원격 비서** | 오스크가 무서운 어르신을 위한 AI 조수 | 고령층 |
| **효자손** | 원격으로 어르신 생활 지원 | 고령층 |
| **AI 정서 케어** | 치매 노인을 위한 감정 지원 시스템 | 치매 환자, 보호자 |
| **AI 중재자** | 이혼 위기 부부의 상담 및 중재 | 부부 |
| **반려견 원격 교정** | 낯가림 심한 반려견의 행동 교정 | 반려동물 보호자 |

### 기존 아이디어 개선 사항

**청각장애인 지원 서비스**
- 차별점 1: 전문 교육자를 길러내는 시스템 도입
- 차별점 2: 감정 시각화 자막 기능 추가

**부동산 중개 서비스**
- 차별점 1: 아바타 기능 (가상 전시 공간, 맞춤형 큐레이션)
- 차별점 2: 로드뷰 기능 (주변 환경 정보 통합)

### 프로토타입 개발
- Canva를 활용한 프로토타입 제작
- 팀원의 이해도 향상을 위한 웹사이트 구축
- 프로젝트의 시각화 및 공유

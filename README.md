### <center>Codin’nator</center>

팀원과 함께 **실시간으로 코드를 편집**할 수 있는 협업 툴

WebSocket을 활용하여 누구나 쉽게 참여할 수 있는 실시간 코드 작성 협업 플랫폼을 제공합니다.

- **개발 기간:** 2026.01.06 ~ 2026.02.06 **(5주)**
- **플랫폼:** Web & Desktop App
- **개발 인원:** 6명
- **기관:** 삼성 청년 SW·AI 아카데미 14기
